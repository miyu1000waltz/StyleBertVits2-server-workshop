# StyleBertVits2-server

- 本リポジトリは、2026-09-16時点のバージョン情報(`requirements.txt`等)での動作を確認しています。
- ビルドは Windows・macOS で確認済みです。
- 確認時点では問題ありませんが、その後発見されたセキュリティホール・脆弱性については追えていない可能性があります。利用にあたってはご留意ください。

## 起動時の処理フロー

`docker compose up`を実行してから、実際にAPIが使えるようになるまでの流れです。

1. `docker compose up`を実行する
2. イメージが無ければ`Dockerfile`に基づいてビルドする(初回のみ。Docker Hub・PyPIへのネットワークアクセスが必要)
3. コンテナ起動時に`start.sh`が実行される
   - `model_assets/`配下に音声モデル(`*.safetensors`)が無ければ、HuggingFaceから`koharune-ami`モデルをダウンロードする(初回のみ。ネットワークアクセスが必要)
4. `uvicorn`の起動処理の中で、以下が順にロードされる
   - pyopenjtalk辞書のビルド(デフォルト辞書+ユーザー辞書を結合)
   - BERTモデル・トークナイザのダウンロード/ロード(初回のみ。ネットワークアクセスが必要)
   - TTSモデル(koharune-ami)のロード
5. ポート`8100`で待ち受けを開始し、`/health`で死活監視される

初回起動時は②③④で複数回ネットワークアクセスが発生するため、社内ファイアウォール等でHuggingFaceへのアクセスが制限されている環境では起動に失敗することがあります。

## 注意事項

### ネットワーク

- APIへのアクセスにはポート`8100`を解放している必要があります。
- 以下のタイミングで外部へのネットワークアクセスが必要です。社内ファイアウォール等で制限されている環境では、事前に疎通を確認してください。
  - ビルド時: Docker Hub(ベースイメージ取得)、PyPI・download.pytorch.org(pipインストール)
  - 初回起動時: HuggingFace(`huggingface.co`) — 音声モデル(`koharune-ami`)とBERTモデルの両方のダウンロードで必要

### WSL2(Windows環境)

- Windows上のDocker Desktopは、`model_assets`等のボリュームマウントにWSL2バックエンドを使用します。事前にWSL2が有効化されている必要があります。
- 会社支給PCなど組織管理下の端末では、セキュリティポリシーによりWSL2やHyper-Vが無効化されている場合があります。その場合はビルド・起動が行えないため、事前に有効化状況を確認してください。

### ライセンス(音声モデル)

- デフォルトで使用する音声モデル`koharune-ami`(HuggingFace: `litagin/sbv2_koharune_ami`)には公式なOSSライセンスの明記がなく、「あみたろの声素材工房」の利用規約に従う形になっています。
- 本リポジトリはこのモデル本体を**同梱・再配布していません**(規約上、モデル自体の再配布が許諾されていないため)。`docker compose up`時に、利用者自身の環境からHuggingFaceを通じて取得する構成にしています。
- 生成した音声を公開・利用する際は、上記利用規約に従い、クレジット表記など必要な対応を各自で行ってください。商用・非商用の別、改変(モデルマージ等)、禁止事項(年齢制限作品・政治利用・なりすまし等)についても規約を確認してください。
- 別の音声モデルを使う場合も、そのモデル配布元のライセンス・利用規約を必ず確認してください。
